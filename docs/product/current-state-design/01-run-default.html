How does Context Engine keep model proposals separate from tool execution?

[ ] Context Engine

The model can only propose a tool call. The runtime looks the tool up in the registry, validates the arguments against the tool's schema, and checks policy before anything runs.

The tool then executes deterministically and returns a structured result, which is passed back to the model for the final answer. The model never executes a tool or changes runtime state itself.
