# Project roadmap

M1 established the repository foundation. M2 delivered the explicit agent state machine. M3 added
deterministic, policy-controlled tool use. M4 provides embeddings, Qdrant-backed vector storage,
retrieval, and the read-only search_documents tool. M5 adds text, Markdown, and PDF processing,
structure-aware chunking, durable source ingestion, and optional lexical BM25, hybrid retrieval,
cross-encoder reranking, and evidence selection. Dense retrieval remains the default. Automatic
context assembly remains future M6 work.
